# Lesson assistant

The optional drawer calls `/api/lesson-assistant` on the same origin. The Worker uses a fixed Cloudflare Workers AI model, course data bundled from the existing curriculum, and up to two recent chat turns. No API keys are sent to the browser and no dependencies were added.

## Free-only operating requirement

On October 14, 2026 the account's Cloudflare Workers plans page showed **Free / $0 / Current plan**, with 10,000 AI neurons per day. The account must remain on Workers Free. On that plan Cloudflare rejects requests after the shared free allowance; this application never upgrades the plan, buys credits, or calls a paid fallback.

`ASSISTANT_ENABLED=true` enables the endpoint. Set it to `false` to disable inference. Before changing the account plan, adding AI Gateway billing, or changing the fixed model, disable the assistant and reassess costs. This flag is an operational switch, not automatic billing-plan detection. The regional rate limiter is an abuse throttle, not a global billing cap. Cloudflare Free is the hard cost boundary. Availability and prices can change.

- Fixed model: `@cf/meta/llama-3.3-70b-instruct-fp8-fast`.
- Maximum 400 output tokens, 600 characters per student question, 8 KiB request body, two previous turns.
- Five requests per minute per network at each Cloudflare location. Anonymous users sharing a network may share the limit.
- No automatic retries, fallback models, paid databases, embeddings, or third-party inference.
- Provider error 3036 gets a daily-allowance message; other failures remain temporary-unavailable errors without exposing provider details.

References: https://developers.cloudflare.com/workers-ai/platform/pricing/ and https://developers.cloudflare.com/workers-ai/platform/errors/.

## Context and privacy

Only known lesson IDs and step indices are accepted. Teaching content is selected from explicit allowlisted fields; quiz banks, answer keys, model answers, grading rubrics, and feedback fields are not supplied. Practice steps offer a study-hint button instead of free-form chat. The Worker omits the original question and any submitted message/history on those steps and requests a different teaching example; custom finance questions remain available on teaching steps. Model behavior is probabilistic: this is a learning aid, not an exam security mechanism or a source of guaranteed financial accuracy. Course links are generated by the server from real lesson IDs, not invented by the model.

Chats remain in page memory, reset on step changes/navigation/refresh, and do not modify existing storage. The server has no chat database, request-body logging, or analytics of conversation text. Cloudflare processes inference and routine technical request data. A dated hash of the connecting IP is used for throttling. The UI and Privacy page explain this before sending.

## Verification and publishing

Run `npm run test:assistant`, `npm run test:quizzes`, `npm run lint`, `npm run build`, `npm audit --omit=dev --audit-level=high`, and `npx wrangler deploy --dry-run`. CI runs these checks. `npm run preview:assistant` serves the built assets and Worker locally; real AI requires an authenticated Cloudflare account and may consume free allowance. A Vite-only preview has no AI endpoint and reports that clearly.

Before production release, test a Cloudflare preview with real model replies: a basic definition, a calculation explanation, a practice hint, an unrelated question, follow-up context, retry on a failed request, and the rate-limit message. Verify closing/Escape/focus restoration, mobile width, lesson direct refresh, notes, and quiz scoring. Tests mock the provider to exercise quota exhaustion without spending the daily allowance.

Rollback: revert the feature commit or set `ASSISTANT_ENABLED=false` and redeploy. Assets, curriculum, scoring, and existing browser storage are independent of the endpoint.
